## Operational and credential variables

These variables are consumed by build/installer/provider entry points rather than `CortexConfig`.

| Variable | Purpose |
| --- | --- |
| `CORTEX_ENV` | Runtime environment label; use `test` only in tests. |
| `CORTEX_DEBUG` | Enable native-host debug logging (`1` only while diagnosing). |
| `CORTEX_JSON2TS_CMD` | Override the schema generator executable. |
| `CORTEX_NATIVE_HOST_PROJECT_ROOTS` | Comma-separated roots the native host may launch. |
| `CORTEX_NATIVE_HOST_PYTHON` | Interpreter written into the installed native-host shebang. |
| `CORTEX_PROJECT_ROOT` | Launcher-agent project root override. |
| `CORTEX_PYTHON` | Launcher-agent interpreter override. |
| `CORTEX_SIGN_IDENTITY` | Developer ID identity used for release signing. |
| `CORTEX_NOTARIZE_PROFILE` | `notarytool` Keychain profile used by release builds. |
| `CORTEX_NOTARIZE_KEYCHAIN` | Non-default Keychain containing the notary profile. |
| `CORTEX_REQUIRE_NOTARIZATION` | Fail the build unless Developer ID signing and notarization succeed. |
| `CORTEX_ARTIFACT_ARCH` | Architecture label verified against the built application. |
| `CORTEX_RELEASE_EVIDENCE_DIR` | Directory for checksums and release-verification evidence. |
| `CORTEX_RELEASE_TAG` | Exact checked-out tag required by release provenance. |
| `CORTEX_SKIP_EXT_BUILD` | Skip browser bundles only when verified bundles already exist. |
| `CORTEX_SKIP_VSCODE_EXT_BUILD` | Skip VSIX creation only when a verified VSIX already exists. |
| `CORTEX_ROOT` | PyInstaller spec root override. |
| `AWS_BEARER_TOKEN_BEDROCK` | Bedrock bearer token; prefer macOS Keychain instead. |
| `ANTHROPIC_API_KEY` | Direct Anthropic credential; used only when that provider is selected. |
| `GOOGLE_APPLICATION_CREDENTIALS` | Vertex ADC file; keep outside the repository. |

Credential values belong in macOS Keychain or the provider's supported credential store. Never commit them to `.env`.
